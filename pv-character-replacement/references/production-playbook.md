# 以高质量成片为目标的制作流程

## 制作约定

提取已有要求，明确源视频、角色/形态、画风、替换范围、声音与交付规格。已有认可稿和封存时间轴先读取，不从零重启。

两个维度分开约定：

| 维度 | 默认 | 何时改变 |
| --- | --- | --- |
| 动作曝光 | `strict_source`，保留真实绘稿变化与原 PTS | 用户同意新增绘制过渡后才用 `adapted_motion`；不增加镜头总长 |
| 审查节奏 | 质量优先，试制和受影响批次通过后扩展 | 用户明确要求全片草稿优先时可先补齐，延期缺陷记未通过 |

`strict_source_draft_preview` 是可莉工程的“原曝光草稿”标记，不是第三种动作算法，也不能直接输入随包的通用时间轴校验器。

开始前核对工具实际能力与额度、可用编解码器及磁盘空间。不承诺固定调用量、并发数、种子或像素锁定。工具不可用时保留入口与原因；不能用原人物、临近姿势、程序绘画或形变伪装缺稿已完成。

## 阶段门槛

| 阶段 | 产出 | 进入下一阶段的依据 |
| --- | --- | --- |
| 来源 | 源文件指纹、逐帧 PTS、真实视频结束边界、音轨规格 | 同一来源顺序解码；帧号和时序不依赖近似 seek |
| 拆稿 | 候选、原尺寸二维差值、独立 cel、人物曝光和其他层相位 | 人工核对眼/手/轮廓等关键局部；候选数不是必需生图数 |
| 风格试制 | 稳定身份锚点、简化规则、代表性高风险合成 | 比例、线宽、色块、发束和饰品稳定；复杂遮挡与文字路线已实际验证 |
| 逐稿生成 | 工具原件、完整 prompt/参考职责、版本与缺陷 | 当前源稿主导姿态；可见角色及肢体计数、关键动作和裁切逐稿确认 |
| 合成 | 背景、新旧 matte、道具/FX/文字及实际输出 | 无旧轮廓、主体孔洞、背景破坏、错相位或不可读文字；验证不遗漏相位 |
| 连续检查 | 相邻、循环、单帧转场和镜头边界证据 | 结构拓扑可追踪，动作幅度/相位正确；检查真实曝光而非均匀接触图 |
| 编码 | 完整单版主片及有声音对照 | 帧数、精确 PTS、尾曝光、音轨载荷/同步、完整解码通过；编码后文字再审 |
| 终版 | 全片原速审阅、问题关闭、固定版本与交付记录 | 必需范围无未解决关键缺陷；技术与美术证据均完整，不把抽样等同全量 |

草稿优先只改变延期时机，不使缺陷变合格。损坏文件、缺稿、错曝光、错声音始终阻断“完整草稿”；关键美术问题可按明确约定延期，但终版前必须解决并复核。

## 每个任务如何记录

保持一份可解析的任务/选稿表，以 `source_sha256 + cel_id + version` 标识输入与版本，不能按生成返回顺序组片。至少包含：

- 源帧、源 PTS、镜头、全部 `[start,end)` 曝光和相机变换。
- 当前原稿、可见人物/肢体、表情/关键姿势、道具接触与遮挡次序。
- 每张实际查看的参考路径、SHA、原生尺寸、角色职责及顺序。
- 完整 prompt、工具原输出与项目副本、实测尺寸/SHA、实际调用成功或失败事件。
- 当前采用版本、来源复用证据、缺陷类别/严重度、影响曝光和下一步。
- 单稿、合成、编码、相邻/循环、原速审阅分别记录：检查者、范围、证据、时间与结果。

`generated`、`selected_draft`、`composite_reviewed`、`encoded_reviewed`、`original_speed_reviewed`、`artistically_accepted` 是不同事实，不自动相互升级。原人物重复核验是 `source_reuse_verified`，不是新人物美术通过。没有记录写 `not_recorded`，不要自动判废或通过。

批次封存 prompt、源/新资产哈希和基线选择；事后更正另写追加记录，不改写旧封存来隐藏错误。选择变化后更新真实覆盖，不靠旧库存/旧报告解释新进度。

## 故障处理顺序

先实际对照五种材料：当前原稿 → 生成 PNG → 新旧人物 matte → 实际合成 → 编码帧。

1. 错误已存在于生成 PNG：修图或重绘；移除导致传播的错误参考。
2. PNG 正确、合成错误：修图层、遮罩、坐标、相位或清板，不重画好稿。
3. 合成正确、编码错误：查 PTS、色彩转换、压缩和音轨流程，不动人物绘稿。
4. 静态看似正确、原速跳变：查稿间幅度、身份/服饰漂移、源别名、曝光及循环接缝。

同方向返修连续无改进时停止该策略。通常不超过两次便换明确依据，例如删错误整图参考、重新查看局部、改用正确字形供体或修错层。次数是默认预算，不是保证修好的定理；没有新证据不能再调同一阈值。细节见 [故障模式](failure-patterns.md)。

## 提速而不透支质量

- 生图前查已映射 cel、其他版本和经核定来源别名。图片库存、独立稿覆盖、帧覆盖、美术验收各自统计。
- 按真实依赖分批；已授权并行时镜头可独立推进，同 cel 单一所有者。正确锚点未就绪时不批量扩散错误。
- 人物与背景/字幕/FX分层缓存；不能为复用人物缓存整幅成片，否则会冻结星点或换词。
- 素材改变检查它的全部曝光、邻接边界和循环；公共规则改变检查所有适用镜头及冻结回归。证据可复用的前提是源、素材、依赖及代码哈希未变。
- 不因补几稿反复导出长前段。选择有意义的完整动作/转场/字幕相位验证；全长检查集中在整片导出阶段。
- 单版主片合成一次，对照复用已完成主片拼接。对照有二次压缩，不替代主片视觉判断，且须独立校验时序/声音。
- 先测合成/解码/编码瓶颈。文件增长、CPU或管道字节是运行证据，不是完成/验收；不杀掉正常长任务重跑，不采样未退出的 MP4。

## 流畅度的验收对象

流畅是演出节奏成立，而不是强制高 FPS。原作的持帧、交替绘稿、停顿和一帧切换可能是设计，应保留。

- 位置：画布、相机和身体锚点分别比较，避免自动包围盒居中/缩放；不能对齐掉真实动作。
- 幅度：眼、嘴、头倾、双肩袖、手、衣摆、发根/中段/发梢逐项对比，不只确认运动方向。
- 拓扑：发束连接、可见手数、领口/衣摆、道具接触和遮挡前后关系稳定；转向时不能凭空换发型或生出第三条肢体。
- 相位：身体、发梢、衣料可有合理滞后；原作不动的锚点不擅自耸肩。字幕/特效不跟随人物矩阵错位。
- 边界：每个动作切换前/切换/后，所有一帧转场，方向反转，循环末→首，修复区间两端均检查。
- 播放：按真实曝光以原速看完整镜头和全片有声音对照；慢放/静图是定位工具，不替代原速。

跳变先修正确稿与动作幅度。在 `strict_source` 下不擅自加插帧；需补绘时明确提出 `adapted_motion` 的拍点和时长取舍，不用光流/morph/dissolve冒充绘稿。

## 可称终版的条件

高质量终版至少完成：全部需要替换的可见人物、所有关键动作/遮挡、全字幕相位/标题/credits、全部镜头/循环的原速审阅，以及独立编码技术验证。主要美术检查不能只抽稀疏截图；风险区的完整连续帧检查之外，还需全片观感。

技术报告不能授予美术通过；没有实际查看的证据不能写已看。若工具无法观看原速、预算不足或关键缺陷仍开放，诚实交付草稿与检查缺口，继续收集反馈，不能承诺 Skill 保证生成模型一次达标。

反馈按时间码定位源帧及 cel，返修其全部复用曝光并检查相邻、循环和文字/道具层；保持其他已认可内容。新版本单独存，重验整体时序和声音，不覆盖认可基线。
