# 已遇故障、处理依据与验证办法

这些模式来自可莉 PV 的实际失败与修复。具体帧号、偏移、阈值和文件注册是案例证据，不是其他项目通用参数。优先按 [制作流程](production-playbook.md) 的五方对照定位；下表中的“已验证”也仅指其明确范围，不承诺可套到全片。

## 拆稿与生图

| 症状 / 已证原因 | 处理方法 | 必须复查 |
| --- | --- | --- |
| 相似画面被合成同稿：整体差值掩盖眼、手、衣褶变化 | 在全分辨率对齐人物ROI，查看AB/RGB差/双色轮廓及关键局部；证据足够才登记来源别名 | 所有曝光、真实表情/关节变化；背景/字/FX仍按当前帧 |
| 候选数和PNG库存被当作动作数 | 分别统计独立已核cel、候选上限、采用版本、有效别名、帧覆盖和美术状态 | 多版本不计新动作；未记录不等于失败 |
| 族标签误识别姿势/空镜，如抱枕被标俯卧、上半身被标脚部 | 以当前原尺寸图及AB为准，重新定实际局部框和人数 | 帽缘、后脑、退场发束、完全被遮住脸的后方人物 |
| 邻稿冻结当前动作或传播错误发束/衣领/第三手 | 去掉错误整帧参考，用正确身份局部+当前原稿+真实差值重绘 | 方向和幅度都要对；后续依赖稿不得沿用失败结构 |
| 嘴形被可爱锚点改成吐舌；红眼修复丢瞳孔 | 原脸局部主导眼睑/视线/嘴形，身份只管固有色形 | 两眼瞳孔/高光、睁闭时刻、非对称刘海；改色不等于表情正确 |
| 局部返修重画整图，目标框外大量变化 | 用原版本作基线，输出全图和框外差值；同方向无改进时换参考或重绘策略 | 相邻/循环、道具和其他已认可区域；不宣称prompt像素锁定 |
| 固定参考裁切已不包含脸或手 | 实际查看裁切，随镜头/人物运动重定范围；保留旧证据并另存新版本 | 当前可见范围、关键手势/袖口连接，不以合法路径代替看图 |
| 风动变成长发跳边或完全僵住；下蹲把衣服整体压扁 | 追踪发根/中段/发梢与衣料固定点；先保原曝光修幅度，必要时经授权补绘 | 反转、回弹、循环；裙片/袖口折叠和身体关节分开 |
| 错记尺寸或中断后重复生成 | 解码实测PNG尺寸；保存工具原件/副本SHA；按job和采用版本恢复 | 原始输出真实存在；参数失败/额度失败不计成功产出 |

## 遮挡、人物 matte 与背景

| 症状 / 已证原因 | 处理方法 | 必须复查 |
| --- | --- | --- |
| 背景恢复后出现旧长发：PNG正常，源前景回灌 | 修合成/源前景归属，限定文件及曝光；不要重画完整正确PNG | 原片/PNG/新旧matte/合成；字区外旧衣/鞋轮廓 |
| 旧发直接在生成PNG中 | 从当前原稿与无冲突身份参考整帧修图，不靠遮罩隐藏人物 | 全部可见人物残片和压缩边缘；修复版本不是新cel |
| 冷色脸、浅发、袖口被sky条件删成洞 | 对该镜头注册已观察fill、封闭色块及线稿支持；旧人删除和新人体保留使用不同依据 | 冷/暖主体独立core、眼白/墨线、完整内部与边缘；“支持区内零差”不充分 |
| 底边播种天空把出画长发当背景；生成天空破坏渐变 | 仅从已确认背景边界连通；旧人离开区域使用来源可观察的背景重建 | 发梢、脖子、渐变接缝、当前源星点；明确重建而非源像素 |
| 特效黄填色变空心或黑线少一点 | 单独登记原FX填色与轮廓，不混入旧人删除mask；按相交所有权检查 | 被手套遮挡的身体检查可排除真实FX，但FX自己的检查不能排除 |
| 道具像素正确但手腕/手指不接触；悬浮钟规则误用于手持钟 | 先校准接触和遮挡次序；按当前源图分离手指/道具前后层 | 手/袖/道具全尺寸连接、所有曝光；规则不跨持物类型套用 |

## 字幕、标题与最终编码

| 症状 / 已证原因 | 处理方法 | 必须复查 |
| --- | --- | --- |
| 文本mask宽泛，带回旧鞋/衣袋；关闭一个区域仍有碎点 | 先核对真实字相位和所有前景入口，只恢复登记笔画alpha | 缺笔和误增字、字区外旧人物、新角色内部浅点 |
| 字与原衣物同色，阈值调试无限循环 | 先证明笔画是否可观察；授权后用真实同句清晰供体，CN/JP单独注册 | 供体完整全文、唯一位置、出现时间、AA/底板重建；不可称原透明度完全恢复 |
| CN错用JP偏移，或供体自身已有缺字 | 分语言核定字形支持与平移，检查完整字而非旧字芯 | 案例CN(-15,0)、JP(-12,0)只适用于该供体；新项目重新测 |
| 描边变粗仍读不清，靴饰与日文字混淆 | 定位几何/低对比与字形混叠；改变有依据的图层或整稿，而非继续扩大halo | 案例4px halo已拒绝；字下隔离/简化靴饰仍须新验证，不能称现成已解决 |
| 字幕换词在人物曝光内部，检测范围没登记却报告通过 | 按实际源帧独立建相位表，每次覆盖范围扩展重新审新增曝光 | 每个语言/标题/credits、字芯/外缘、未覆盖项；拒绝空集合通过 |
| 文字恢复额外添加原片没有的词 | 对照全文、位置和时间，安全字框内恢复当前源像素，禁止覆盖人物 | 既检查缺字，也检查误增字；来源供体不跨句套用 |
| 有字芯RGB且精确PTS，但最终视频仍缺字或动作跳变 | 编码后实际查看连续帧及原生字区，再按原速审全片 | 有损字边/对比、全片字幕相位、相邻结构、循环；技术和美术结论分开 |
| 名义24fps或包duration被当成展示曝光，尾帧边界被误判 | 记录整数PTS/time base和显式流结束；展示顺序与包/DTS顺序分开，保留包端点差异诊断 | 实际逐帧PTS、最后曝光、音频同步；来源未声明结束时不猜测，不放宽容差 |

## 工程效率与可追溯性

| 症状 / 已证原因 | 处理方法 | 必须复查 |
| --- | --- | --- |
| 每补少量稿都重导长前段，进度受局部反复定稿拖慢 | 有意义的整动作/相位做增量检查，缓存未变版本，集中导出全长 | 代码/输入哈希变更时失效范围要重测；提速不绕过终版关键门槛 |
| 生图结束但全片输出仍慢，被误认为卡死 | 分别观察合成与FFmpeg CPU/文件增长，给正常长任务完成机会；对照复用主片 | 管道字节/文件存在不是完整导出；进程退出后才采样和校验 |
| worker限制被误记为生图工具失败；重派渠道丢失历史 | 区分实际事件，保留已生成job和未完成入口；按正常恢复续作 | 不伪造调用、不静默切通道；现成正确稿不重复生成 |
| 合并私有稿回退旧选稿，历史报告被改写 | 单一所有权、私有proposal、采纳前/后差异核对，旧基线/封存不可变 | 所有新SHA/尺寸与工具原件；旧选择不变；各版本缺陷都计入当前清单 |

## 不能当成已解决的案例结尾

本案例最终交付的是完整首版草稿：3658帧，两版各17项技术检查与81项回归通过，但美术终版尚未验收。后段2145/2146的字幕丢失、2162..2164旧长发残留、3234..3236与3258..3260字幕缺笔、3470靴区歌词和3657标题/credits丢笔均有实际编码证据。f1129也有服饰/帽形/眼态跳变。

已注册2121..2144的24帧修复不证明2145以后正常；28个采样点不等于全片原速审阅。把上述问题作为下一次终版 gate 的必查风险，而不是“完整映射后可放心导出”的成功范式。原始案例及脚本来源见 [脚本地图](script-map.md)。
